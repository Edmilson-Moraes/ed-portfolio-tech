# Shopping List CLI

Projeto simples em Python para gerenciamento de lista de compras via terminal.

## Objetivo
Praticar:
- Estruturas de repetição
- Manipulação de listas
- Tratamento de exceções
- Interação com usuário (CLI)

## Funcionalidades
- Adicionar itens
- Remover itens
- Listar itens

## Como executar
```bash
python main.py
